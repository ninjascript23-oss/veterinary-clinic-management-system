# 🐾 Paws & Care - Veterinary Clinic Management System

A production-ready, fully responsive 5-page Full-Stack Web Application engineered using **Python Flask**, **SQLite3**, and **Bootstrap 5**. This system features modular template inheritance with secure backend database pipelines.

---

## 🚀 Key Software Architectures
* **Database Security:** Parameterized SQL queries implemented to completely block basic SQL Injection attacks.
* **POST-Redirect-GET Pattern:** Engineered to completely prevent duplicate form entry errors on page refresh.
* **Modular Template Layouts:** Structured using Jinja2 inheritance featuring discrete base layouts (`base.html` and an isolated `admin_base.html` workspace).
* **Dynamic Content Grid:** Private administrative dashboard displaying user contact logs directly from the SQLite database.
